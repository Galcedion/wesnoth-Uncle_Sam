# wesnoth-Uncle_Sam

Modification for Battle for Wesnoth. Regular and equal income for all players with no other source of income.

## About

Uncle Sam is a modification that acts as a gamemode, changing the way Battle for Wesnoth is played. Every player has the same starting gold and income, with no other incomes available.

The modification is intended for multiplayer and thus disabled for campaigns.

## Options

The following options can be set ahead of the game:

- Starting Cash
- Cash Rate
- Rate Cycle
- Ingame Messages

## Testing

Developing and testing on The Battle for Wesnoth 1.16
